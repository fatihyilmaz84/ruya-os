## Host facts learned
- WSL: `wsl -- bash -c "$(...)"` through PowerShell mangles `$`; put commands in a script file and run it with `wsl -d FedoraLinux-44 -- bash /mnt/c/...`. A WSL connection can time out (WSAETIMEDOUT) during heavy dnf/podman: rerun; background processes die with the session (no nohup survival).
- `cmake` build of only `ruyacompositor` does not link: a link failure appeared only in the image build. A full-target compile in WSL needs `qt6-qtwayland-devel qt6-qtbase-private-devel qt6-qtdeclarative-devel qt6-qtmultimedia-devel qt6-qttools-devel qt6-linguist qt6-qtshadertools-devel qt6-qtsvg-devel cmake ninja-build gcc-c++` (installed in the WSL distro now).
- QEMU virtio GPU has no `/sys/class/graphics/fb0`; use `/sys/kernel/debug/dri/*/state` (`mode:` line) for the CRTC mode. Qt eglfs follows `QT_QPA_EGLFS_KMS_CONFIG` with names like `Virtual1`/`HDMI1` and `"WxH@Hz"` (proved).
- Reviewers' revert checks rebuild shell\build-win; the main checkout's build is restored by `revert-check.ps1`.
- Older notes (SELinux/PID 1 pipes, `bootc usroverlay` loop, `busctl --json=short`, `QSettings`, heredocs and backslashes) are in `image/CLAUDE.md`, `docs/dev-setup.md` and git history of this file.
