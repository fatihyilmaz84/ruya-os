# T-243 — Developer guide chapter and two sample packages

Status: todo · Phase: 7 · Depends: T-233 · Area: docs, samples · Size: M · Owner: builder · Developer surface: public-format

## Goal
An outside developer can package a game as a `.play`, sign it, test it on a console and understand the security rules, from the guide and two working samples alone.

## Read first
- `docs/specs/05-play-packages.md` (all), `docs/developers/README.md` and one chapter for style (`saves-and-data.md`), `scripts/lint-dev-docs.ps1` (what the lint checks: links, code blocks, sample quotes, "Sources" footer), `samples/hello-game/`
- T-233 Outcome (the tool as built)

## Scope
1. `docs/developers/play-packages.md` (chapters or one long file, linked from the README): what a package is and is not (Flatpak vs `.play`); layout; `play.json` field reference with the example; art specification with the composition guide for the hero (diagram of the safe zones) and the icon safe area; choosing a runner `source` (with the size/compatibility trade-off table: bundled, system, prefer-system, newest); Wine prefix and saves paths; permissions and what each costs the player; signing and key handling (never commit a key; how continuity and rotation work); updates (store vs feed vs hand, privacy); legal duties for bundled code; testing on a console in developer mode; troubleshooting with the validator's messages.
2. `samples/hello-play-native/`: a tiny native Linux game (reuse or build on `samples/hello-game`), packaged with real placeholder art (CC0, generated by a script in the sample).
3. `samples/hello-play-wine/`: a Windows program built with a cross-compiler (`x86_64-w64-mingw32`, script provided, no binary blob in git) using `source: newest`, a saves path in the prefix, a first-run setup step that is a no-op, to show every field.
4. A `scripts/build-samples` step documented (not run in `dev.ps1 test` if it needs a cross-compiler; the lint checks that the sample manifests validate with `ruya-pack validate` when the tool is built).
5. Turkish is not required for the guide.

## Out of scope
- Marketing/store submission process (owner-level), Proton and emulator how-tos (later, after T-244 and the owner's D2).
